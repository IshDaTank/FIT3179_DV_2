- Recognition scatter → three period geographic small-multiple maps (one chart). Each panel maps dedications within the labelled period.
- Regional bubble plot → ranked lollipop chart; removed duplicate size encoding.
- Venue overlap heatmap → categorical symbol matrix. Legend in chart reading: ● recorded, ◯ broader area, — not listed.
- Final heatmap → coordinated state comparisons with separate quantitative scales for reserves and competition stops (one composite chart).
- Australian tour map → numbered sequence / route map. Lines are **not** observed travel flows; the decorative arrow indicates order only.
- Calendar matrix → explicit ascending numerical month sort.
